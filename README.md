# 🌙 Aadhi Mulaqaat - Real-Time Chat & Community Platform

> *"Where conversations turn into timeless connections."*

Aadhi Mulaqaat is a feature-rich, modern, and responsive real-time chat application built with vanilla JavaScript, Tailwind CSS, and Firebase. It provides multiple communication channels including a Global Lounge, 1-on-1 Direct Messages (DMs), Group Communities, Realtime Media Status Stories, and a private AI companion.

---

## ✨ Key Features

*   🌍 **Global Lounge:** A public chat room for all connected users.
*   💬 **1-on-1 Direct Messaging (DMs):** Private conversations with live active status indicators and user blocking features.
*   🤖 **Mulaqaat AI ✨:** A dedicated smart AI companion integrated privately for each user.
*   📸 **24-Hour Realtime Status Stories:** Post text, image, or video status updates that automatically expire after 24 hours (with manual delete options).
*   🎨 **Custom Chat Wallpapers:** Personalize your chat screen background with custom images or preset gradients.
*   🔍 **In-Chat Search & Member Filters:** Real-time keyword search across messages and specific member filtering inside group chats.
*   📊 **Interactive Live Polls:** Create, publish, and vote on live polls directly inside chats.
*   🎙️ **Voice & Media Messaging:** Support for image attachments, documents, audio voice notes, and emoji pickers.
*   📞 **WebRTC Peer-to-Peer Calls:** Real-time HD audio and video calling screens powered by WebRTC technology.
*   👤 **Profile Management:** Update your display name, bio, and profile picture in real-time.
*   🎨 **Dynamic Themes & Particle Background:** Choose from 5 custom color palettes with dark/light mode toggles and a continuous particle canvas animation across the entire website.

---

## 🛠️ Tech Stack

*   **Frontend:** HTML5, Tailwind CSS, FontAwesome Icons, Google Fonts (Plus Jakarta Sans)
*   **Scripting:** Vanilla JavaScript (ES Modules)
*   **Backend & Database:** Firebase Authentication & Cloud Firestore (Real-time sync)
*   **Realtime Media Calls:** WebRTC API
*   **Cloud Storage:** Cloudinary API for media uploads
*   **Alerts & Modals:** SweetAlert2
